# ☕ Java | Ruta de Aprendizaje

## 📖 Sobre este repositorio

Este repositorio documenta mi proceso de aprendizaje y fortalecimiento de habilidades en **Java**, desde los fundamentos del lenguaje hasta conceptos avanzados de programación orientada a objetos y desarrollo backend.

Aquí encontrarás ejercicios prácticos, laboratorios, retos de programación y pequeños proyectos que reflejan mi evolución como desarrollador.

Mi objetivo es construir bases sólidas en Java, aplicar buenas prácticas de programación y avanzar progresivamente hacia el desarrollo de aplicaciones con **Spring Boot**.

---

## 🎯 Objetivos de aprendizaje

- Comprender los fundamentos y la sintaxis de Java.
- Desarrollar habilidades de lógica y resolución de problemas.
- Aplicar correctamente los principios de programación orientada a objetos (POO).
- Trabajar con estructuras de datos y colecciones.
- Aprender el manejo de excepciones.
- Implementar código limpio, modular y reutilizable.
- Incorporar pruebas unitarias con JUnit y Mockito.
- Preparar las bases para el desarrollo backend con Spring Boot.

## 💡 Metodología

Mi aprendizaje se basa en la práctica constante y la aplicación de conceptos mediante ejercicios y proyectos.

Cada actividad busca fortalecer cuatro aspectos:

1. **Comprensión:** entender cómo funciona cada concepto.
2. **Implementación:** llevar la teoría a código funcional.
3. **Buenas prácticas:** escribir código legible, organizado y mantenible.
4. **Mejora continua:** identificar errores, refactorizar y explorar soluciones alternativas.
